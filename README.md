# 👑 Iron Crown

**Fight. Survive. Never Surrender.**

Iron Crown is an endless 2D platformer where you play as a former soldier transformed into a powerful cyborg, trapped inside a hostile environment.

There is no escape. No final destination. Only an endless fight for survival.

## 🎮 Gameplay

Your objective is simple: survive as long as possible.

- **Movement:** Move left and right using `A` and `D`.
- **Jump:** Jump to overcome obstacles.
- **Shoot:** Use the mouse button to attack enemies.
- **Shield:** Deploy your shield to defend yourself.

## ✨ Features

- Endless platforming gameplay.
- 2D side-scrolling environment.
- Cyborg protagonist.
- Shooting mechanics.
- Defensive shield ability.
- Survival-focused gameplay.

## 🛠️ Built With

- [Godot Engine](https://godotengine.org/)
- GDScript
- 2D game assets
